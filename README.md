A simple HTML educational project showcasing a cat photo gallery website. This is a beginner-level exercise from freeCodeCamp that demonstrates fundamental HTML structure, semantic elements, forms, and links. It's a static webpage with no backend logic—useful as a learning reference for HTML basics.

### Stack
- **Language:** HTML
- **Framework / runtime:** Static HTML (browser-rendered)
- **Notable libraries:** None (plain HTML, no external dependencies)

## How it's organized
```
Cat PhotoApp.html          Main HTML file with complete webpage structure
README.md                  Minimal documentation (title + description)
LICENSE                    Apache 2.0 license
```

**How it fits together:** The single HTML file is self-contained. It loads when opened in a browser and displays a multi-section page via semantic tags: a header section with cat photos and links, a list section covering what cats love/hate, and an interactive form for submitting cat photo URLs. All external resources (images, links) point to freeCodeCamp's CDN.

## How to run it
Open the file directly in any browser:
```bash
# Navigate to the repo on GitHub and click "Cat PhotoApp.html" to view it
# Or clone locally and open with a browser:
open "Cat PhotoApp.html"
# or
start "Cat PhotoApp.html"  # on Windows
```

No build step, server, or dependencies required.
